# W-BOT 🤖

W-BOT is an AI-powered WhatsApp assistant that provides smart and useful AI-powered conversations directly through WhatsApp.

## ✨ Features

- 💬 AI-powered conversational chat
- 📱 WhatsApp integration
- 🧠 Context-aware AI responses
- ⏰ Reminder support
- 📝 Notes and personal assistant features
- 🌐 FastAPI backend
- 🗄️ MongoDB database
- 🔌 REST API
- 🤖 AI provider integration

## 🛠️ Tech Stack

- **Python**
- **FastAPI**
- **Node.js**
- **MongoDB**
- **WhatsApp Web**
- **Google Gemini / AI APIs**
- **REST API**
